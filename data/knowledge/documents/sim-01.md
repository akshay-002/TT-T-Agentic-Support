# SIM and eSIM activation

## Compatibility
The fictional DemoPhone device catalog records whether eSIM is supported for each owned device. Do not infer support from a brand name or claim that a real handset has the same specifications. A physical-SIM device cannot be assumed compatible with eSIM.

## Activation help
If an activation code fails, ask for the error wording without requesting the code itself. Check whether the issue concerns a new activation, an existing line, or a device change. Guide the customer to the approved device settings and official activation channel. A phrase containing “code” can be a legitimate telecom question; it is not necessarily a software-development request.

## Sensitive changes
SIM replacement and eSIM reprovisioning can affect account access and require secure verification and human handling. The MVP may explain these steps or record a ticket. It cannot generate a SIM profile, reveal an activation secret, bypass verification, or execute a replacement.
