# Mobile data troubleshooting

## Safe first checks
Confirm that the device has mobile data enabled and airplane mode disabled. Ask whether the issue affects one device or multiple lines. Check a current area outage report before repeating device troubleshooting. If safe for the customer, suggest restarting the device and checking the preferred network mode.

## Evidence
An unlimited plan does not guarantee 5G coverage at every location. A suspended line may not have mobile service even without an outage. Account state and plan information must be read through an authorized tool; never infer them from the wording of a complaint.

## Limits
Do not suggest a factory reset, erase an eSIM, run scripts, or ask for remote access to the device. If basic checks fail, offer a support ticket with the affected masked line, approximate area, and error description. The MVP handles outage lookup and policy guidance; detailed device diagnostics are a later feature.
